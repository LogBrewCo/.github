# Security policy

## Report a vulnerability

Report it privately. Do not open a public issue.

- On GitHub, open the repository's Security tab and select
  "Report a vulnerability". This works in every LogBrew repository.
- Or email security@logbrew.co.

Tell us what is affected, how to reproduce it, and what an attacker could do.
Use test accounts and synthetic data. Do not access other people's data, and
stop as soon as you can show the problem.

We confirm that we got your report, keep you updated while we fix it, and
credit you in the advisory if you want.

## Supported versions

We fix security problems in the latest release of each SDK, the CLI, and the
skills. The hosted MCP server, API, and web app always run the current
version.
