LogBrew is error tracking, logs, traces, and product analytics for developers
and coding agents. Your apps send telemetry with a LogBrew SDK. You and your
agent read it from the web app, the `logbrew` CLI, the API, or the hosted MCP
server. Generous free tier, no card needed.

| Repository | What it holds |
| --- | --- |
| [sdk](https://github.com/LogBrewCo/sdk) | SDKs for JavaScript, Python, Go, Java, Kotlin, Swift, Objective-C, .NET, Ruby, PHP, Rust, C, C++, Unity, and their frameworks |
| [cli](https://github.com/LogBrewCo/cli) | The `logbrew` CLI, with JSON output for scripts and agents |
| [mcp](https://github.com/LogBrewCo/mcp) | The hosted MCP server at `https://mcp.logbrew.co/mcp` |
| [skills](https://github.com/LogBrewCo/skills) | Agent skills and the Claude Code plugin |
| [docs](https://github.com/LogBrewCo/docs) | The source of [docs.logbrew.co](https://docs.logbrew.co) |
| [homebrew-tap](https://github.com/LogBrewCo/homebrew-tap) | Homebrew formula for the CLI |

Start with the [quickstart](https://docs.logbrew.co/quickstart). Report a
security problem to security@logbrew.co. Anything else goes to
support@logbrew.co or an issue in the repository it concerns.
